## Daftar Modul & Topik Praktikum

* **Pertemuan 1 - 5:** Pengenalan Lingkungan Python, Dasar Pandas DataFrame, Statistika Deskriptif, dan Visualisasi Data.
* **Pertemuan 6:** Persiapan Data untuk Machine Learning (*Data Preprocessing*: Encoding, Scaling, dan Train-Test Split).
* **Pertemuan 7:** Pengantar Machine Learning & *Linear Regression* (Regresi Linear).

### Bagian 2: Algoritma Klasifikasi & Unsupervised Learning (UAS)
* **[Pertemuan 9: Algoritma Klasifikasi (Bagian 1)](./pertemuan9.ipynb)** — Mempelajari *Logistic Regression*, *Decision Trees*, serta evaluasi metrik (*Confusion Matrix*, *Accuracy*, *Precision*, *Recall*, dan *F1-Score*).
* **[Pertemuan 10: Algoritma Klasifikasi (Bagian 2) & Churn](./pertemuan10.ipynb)** — Metode *Ensemble Learning* (*Random Forest*) dan teknik penanganan *Imbalanced Dataset* menggunakan *SMOTE*.
* **[Pertemuan 11: Unsupervised Learning (Clustering)](./pertemuan11.ipynb)** — *K-Means Clustering*, *Hierarchical Clustering*, dan penentuan jumlah klaster optimal (*K*) menggunakan *Metode Elbow* (*WCSS*).
* **[Pertemuan 12: Asosiasi Data & Sistem Rekomendasi](./pertemuan12.ipynb)** — *Market Basket Analysis* menggunakan Algoritma Apriori (*Support*, *Confidence*, *Lift*) serta konsep dasar *Collaborative/Content-Based Filtering*.
* **[Pertemuan 13: Deep Learning & NLP Dasar](./pertemuan13.ipynb)** — Pengantar arsitektur *Artificial Neural Network* (ANN) serta pemrosesan teks sederhana menggunakan *TF-IDF* untuk analisis sentimen.

## Kesimpulan Umum Perjalanan Belajar Data Science (Pertemuan 1 - 13)
Seluruh rangkaian praktikum ini memberikan pemahaman yang komprehensif mengenai alur kerja seorang *Data Scientist* (*end-to-end data science pipeline*). Mulai dari pembersihan dan pengolahan data mentah (*data wrangling* & *preprocessing*), penerapan model *Supervised Learning* untuk regresi dan klasifikasi (dengan perhatian khusus pada penanganan data tidak seimbang), eksplorasi pola tersembunyi melalui *Unsupervised Learning* dan asosiasi keranjang belanja, hingga pengenalan dasar terhadap *Deep Learning* serta pengolahan bahasa alami (*NLP*). Portofolio ini mendokumentasikan kemampuan analitis dalam mengevaluasi model menggunakan metrik yang tepat guna memecahkan permasalahan di dunia nyata.
